# Security policy

Security fixes target the latest version on the default branch. Older releases do not have a separate support commitment.

Do not post secrets or exploitable private details in a public issue. If available, use **Security → Report a vulnerability** for private reporting. Otherwise, open a minimal issue asking the maintainer for a private channel without posting exploit details.

For currency-detection mistakes, formatting problems, or inaccurate estimates, use a normal bug report with a redacted example. Estimates do not guarantee checkout prices or tax treatment.
